# PiGigs 🚀
سوق رقمي ممتثل للخدمات المصغرة يعمل حصرياً داخل بيئة متصفح **Pi Browser** ويستخدم عملة Pi كوسيط نفعي حقيقي لتبادل المنافع والخدمات.

Developed by **@Fuad207**. An independent utility app.

## 🛠️ خطوات التشغيل المحلي والدبليو بي أيه (Local Setup)
1. قم بنسخ ملف `.env.example` إلى ملف جديد باسم `.env` في المجلد الرئيسي وقم بملء البيانات والمفاتيح الخاصة بـ Firebase و Pi Developer Portal.
2. قم بتنفيذ الأمر الموحد في جذر المشروع لتثبيت كافة الحزم للـ Client والـ Server دفعة واحدة:
   ```bash
   npm install

```
 3. أطلق بيئة التطوير التجريبية والمزامنة الفورية بضغطة زر واحدة:
   ```bash
   npm run dev
   
   ```
## 🔒 معايير الإنتاج والأمان العالي (Production Ready)
 * قواعد الـ Cloud Firestore محمية بالكامل بحيث يمنع أي اتصال بالـ Client من العبث بالبيانات، وتتم الكتابة بالكامل من السيرفر.
 * تم معالجة وتفادي التلاعب بالأسعار (Price Tampering) عبر مطابقة الدفع بخوادم الـ API التابعة لـ Pi Network بالخلفية.
